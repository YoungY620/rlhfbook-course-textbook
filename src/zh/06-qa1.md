## 数据与指令微调

> **对于合成 SFT 数据，一个教师模型是否比多个教师模型更好？**

经验上，近期许多开源配方发现，*单一*强教师往往效果最好。OpenThoughts3 使用 QwQ-32B 作为唯一教师，生成了 120 万条推理示例（Guha et al. 2025）。Olmo 3 的推理 SFT 阶段也采用了类似模式，用一个强教师生成大规模合成混合数据（Team Olmo 2025）。实践中，Qwen3-32B 和 QwQ-32B 时代的教师模型仍然显得异常强劲。悬而未决的问题是：为什么更大、更新或“更聪明”的模型并不总是迁移得更好——分布匹配、冗长程度、格式以及过度编辑可能都起作用。

> **教师模型的分布是否应该与基础模型匹配？**

实践中是的，但其机制尚未完全理解。如果教师在风格、词表和推理模式上与基础模型接近，那么它生成的补全通常更容易被学生模仿。如果教师规模或能力远超学生，它可能生成学生无法稳定复现的答案，这会浪费梯度预算或引入幻觉行为。目前没有干净的理论规则，这是一个活跃的经验问题。

> **SFT 混合数据中平衡各个领域有多重要？**

对于构建通用模型非常重要，而实际解决方案并不出人意料：更难的任务通常分配更多词元。一个好的混合数据需要在每个下游领域（对话、数学、代码、指令遵循、安全等）都有足够代表性，并对困难任务赋予足够权重，以免模型欠拟合它们。关键在于混合比例与策展循环：组合现有数据集、评估、发现弱点、补充针对性数据。 unchecked 地扩展单一领域往往会损害通用能力。

## 奖励模型与奖励设计

> **是否存在覆盖成对奖励模型、ORM、PRM 与生成式奖励模型的统一基准？**

不存在。这四类模型需要不同的监督方式并产生不同的输出：

| 模型 | 输入 | 输出 | 监督 |
|---|---|---|---|
| 成对奖励模型 | 提示 + 两条补全 | 标量偏好分数 | 被选/被拒对 |
| 结果奖励模型 | 提示 + 一条补全 | 每个词元的正确性概率 | 二元结果标签 |
| 过程奖励模型 | 提示 + 推理轨迹 | 步骤边界处的分数 | 步骤级标签 |
| 生成式奖励模型 | 提示 + 两条补全 | 自然语言裁决 | 基于提示的评判 |

理论上，单个标注数据集可以重新标注以支持全部四类，但社区已经分裂为多个独立基准（RewardBench、RewardBench2、PRM Bench、ProcessBench、RewardMATH 等）。这种碎片化对于一个正在成熟的领域来说是正常的，但也让横向比较困难。首个奖励模型基准 RewardBench 帮助建立了公共基础设施（Lambert et al. 2025），此后该领域迅速扩展。

> **为什么使用词元级别奖励而非序列级别奖励？**

这个短语有两种含义，答案取决于你指的是哪一种。

**奖励粒度** 指的是*什么*获得奖励：只有最终答案（序列级别），还是中间信号，例如步骤正确性、KL 惩罚或格式奖励（词元级别或步骤级别）。过程奖励模型（PRM）的提出正是为了给推理提供更密集的步骤级监督（Lightman et al. 2024）。更密集的奖励有助于信用分配，尤其在长思维链训练中。

**损失粒度** 指的是每词元损失如何聚合为标量。两种常见模式是：

```python
# 按序列归一化：每条补全权重相同
loss = ((pg_loss * mask).sum(dim=1) / mask.sum(dim=1)).mean()

# 按词元归一化：每个生成词元权重相同
loss = (pg_loss * mask).sum() / mask.sum()
```

按词元归一化被 DAPO 采用（Yu et al. 2025）。它让更长的补全获得更多梯度，这有助于长思维链强化学习，因为实际被采样的词元会收到更强的学习信号。反方观点是，如果奖励只是最终答案的正确性，那么序列级优势仍然很自然；GSPO 将重要性比推回序列级别（Zheng et al. 2025）。

## 强化学习数学与符号

> **PPO 中是否只能用 GAE 计算优势函数？**

不是。RL 速查表中的 PPO 裁剪目标是：

$$
J(\\theta) = \\mathbb{E}\_t\\!\\left[\\min\\!\\left(\\rho\_t(\\theta)\\hat{A}\_t,\\; \\text{clip}(\\rho\_t(\\theta),\\, 1-\\varepsilon,\\, 1+\\varepsilon)\\hat{A}\_t\\right)\\right]
$$

其中 $\\hat{A}\_t$ 可以有多种计算方式。广义优势估计（GAE）是最常见的选择（Schulman et al. 2015），但不是必须的。替代方案包括：

- 蒙特卡洛：$\\hat{A}\_t = G\_t - V(s\_t)$，即完整回报减去价值基线。
- 单步 TD：$\\hat{A}\_t = r\_t + \\gamma V(s\_{t+1}) - V(s\_t)$。
- n 步回报。

实践中，几乎所有面向大语言模型的 PPO 实现都使用 GAE，因为它在偏差与方差之间平衡得很好，通常取 $\\lambda \\approx 0.95$、$\\gamma = 1.0$。理论上也可以不用 GAE、直接使用原始价值模型，但这种情况很少见。

> **$\\rho$ 的形状是什么？**

重要性采样比为：

$$
\\rho\_t(\\theta) = \\frac{\\pi\_\\theta(a\_t \\mid s\_t)}{\\pi\_{\\theta\_\\text{old}}(a\_t \\mid s\_t)}.
$$

在语言模型代码中，各张量的形状如下：

- $\\pi(\\cdot \\mid s\_t)$ 是词表形状：`[B, T, V]`。
- $\\pi(a\_t \\mid s\_t)$ 在采样的词元处 gather：`[B, T]`。
- $\\rho\_t$ 是每个词元的标量；rollout 张量为 `[B, T]`。

```python
# 词表上的 logits/logprobs：[B, T, V]
old_logps_all = old_policy.log_softmax(logits_old, dim=-1)
new_logps_all = policy.log_softmax(logits_new, dim=-1)

# 采样的词元 id：[B, T]
actions = input_ids[:, 1:]

# 只 gather 被采样词元的概率：[B, T]
old_logps = old_logps_all.gather(-1, actions.unsqueeze(-1)).squeeze(-1)
new_logps = new_logps_all.gather(-1, actions.unsqueeze(-1)).squeeze(-1)

# 每个被采样词元的重要性采样比：[B, T]
rho = torch.exp(new_logps - old_logps)
```

## PPO 实现与调试

> **为什么 PPO 对策略损失和价值损失都使用 `torch.max`？**

因为 PPO 被写成**要最小化的损失**，`torch.max` 会选择裁剪项与未裁剪项中更保守的一个。策略损失为：

```python
# PPO 最小化负策略目标
pg_loss_unclipped = -advantages * ratio
pg_loss_clipped = -advantages * torch.clamp(
    ratio, 1.0 - eps, 1.0 + eps
)

# 选择更保守 / 更差的损失
pg_loss = torch.max(pg_loss_unclipped, pg_loss_clipped)
```

当优势为正时，未裁剪项希望增大该动作的概率。一旦比率移动超过 $1 + \\varepsilon$，裁剪项会变得更大（负得更少），因此 `torch.max` 会选择它，梯度随之停止。这防止了过度强化。当优势为负时，对称逻辑防止过度抑制。

价值函数使用相同的模式：

```python
# 价值裁剪：不让 critic 跳得太远
v_clip = old_values + torch.clamp(
    v_pred - old_values, -vf_eps, vf_eps
)

vf_unclipped = 0.5 * (v_pred - targets) ** 2
vf_clipped = 0.5 * (v_clip - targets) ** 2

# 优化更差的价值误差
vf_loss = torch.max(vf_unclipped, vf_clipped)
```

策略裁剪限制策略漂移，价值裁剪限制 critic 漂移。两种情况下 `torch.max` 都训练更差的误差，从而使更新保持保守。

## 人类反馈运营

> **随着合成数据变得越来越简单，数据标注公司应该如何保持价值？**

价值正从低技能、大批量的标注转向专家领域工作。随着前沿模型能够为常规问题生成高质量合成答案，人类标注者越来越多地被需要于法律、金融、医疗和咨询等专业领域，因为这些领域的正确性、细微差别和信任至关重要。商业模式从“更多标注员”转向“更好的专家”，以及让专家能够给出更丰富、更可靠反馈的工具。

## 要点小结

- **先修知识：** 语言建模基础加机器学习入门即可起步；课程面向早期研究生，但实践者也可接受。
- **合成 SFT：** 一个匹配良好的强教师通常优于多个教师；领域平衡和分布匹配比教师规模本身更重要。
- **奖励模型格局：** 成对奖励模型、ORM、PRM 和生成式奖励模型扮演不同角色，并在不同基准上评估；目前尚无统一基准。
- **词元级 vs 序列级：** 区分奖励粒度（最终答案 vs 步骤/词元奖励）与损失粒度（按序列 vs 按词元聚合）。每种选择都会影响长度偏差和信用分配。
- **PPO 优势函数：** GAE 是标准做法但非强制；$\\rho\_t$ 是形状为 `[B, T]` 的每词元标量，由对数概率差计算得到。
- **PPO 裁剪：** 对负损失使用 `torch.max` 会选择保守分支，防止过度强化和过度抑制。价值函数使用相同思想。
- **人类反馈运营：** 标注价值正沿技能阶梯向上移动，进入专家领域，而非消失。
