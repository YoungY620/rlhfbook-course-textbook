# Bilingual terminology

## How to read this file

- `term`: canonical English term used in the English book.
- `zh`: canonical Chinese translation used in the Chinese book.
- Optional `aliases`: other English spellings that should also be linked.
- Optional `note`: disambiguation or usage note.
